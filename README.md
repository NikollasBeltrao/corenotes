# CoreNotes

Aplicação de notas com autenticação, criada com React, TypeScript, Laravel
e MariaDB. O frontend está em `corelab-challenge-web-app-php` e a API em
`corelab-api-challenge-php`.

[Acessar demonstração](https://nikollas-beltrao-projects.duckdns.org:8440/).
Crie uma conta usando dados fictícios e uma senha que não utilize em outros
serviços.

Os projetos possuem instruções próprias em seus respectivos diretórios.
Variáveis de ambiente e dados de banco não fazem parte do repositório.
